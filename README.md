# manager-server

Сервис внешних обращений для СЭП Чата. Принимает сообщения из виджета и
подключённых каналов, связывает обращения с клиентом, управляет ответственным
и выполняет синхронизацию контактов с ЕРП.

Задача и рабочая ветка: **manager**.
Редакция документов: **0.2 от 10.09.2026, рабочий план**.
Владелец разрешил перейти к реализации. В manager-client готов первый этап
виджета с отдельным демосервисом. Производственное приложение manager-server
и интеграции чата/ЕРП ещё не реализованы.

Начать рассмотрение следует с [поэтапного плана](docs/PLAN.md).

Требования к виджету находятся в `pksep/manager-client`,
файл `docs/WIDGET_SPEC.md`. В соседнем локальном клоне это
[WIDGET_SPEC.md](../manager-client/docs/WIDGET_SPEC.md).

Основная схема: виджет/каналы ↔ `manager-server` ↔ сервер СЭП Чата;
`manager-server` ↔ ЕРП. `sep-bot-api` не участвует.

Для продолжения задачи дополнять эти документы и использовать ту же ветку
`manager` в каждом затронутом репозитории. Для чата основа будущих PR — `canary`.
У пустых новых репозиториев GitHub указывает `main` по умолчанию, но фактических
веток `main` и `canary` пока нет. Порядок первого опубликования зафиксирован
как вопрос подготовки репозиториев, без создания лишних feature-веток.
