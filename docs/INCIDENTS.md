# Журнал подтверждённых ошибок manager-server

## Проверка каналов падает до запроса к площадке (09.10.2026)

- **Поведение:** проверка и регистрация каналов могут завершаться
  `CHANNEL_NETWORK_ERROR` до получения ответа API. Webhook-секрет и ключи
  площадки при этом не являются причиной этого конкретного сбоя.
- **Причина:** закреплённый DNS lookup всегда вызывал callback с одиночным
  адресом и семейством IP. При `options.all=true` сетевой стек ожидает массив
  объектов `{ address, family }`. Регрессионный тест на Bun 1.3.14 подтвердил
  нарушение контракта и отказ настоящего локального TCP-соединения.
- **Предотвращение:** при `all=true` возвращать массив только с ранее
  проверенным адресом; иначе сохранять одиночный формат. Не выполнять
  повторное разрешение имени и не обходить запрет внутренних адресов.
- **Автоматическая проверка:** `bun test tests/unit/channel-lookup.test.ts`
  проверяет оба формата для IPv4/IPv6, отсутствие `all` и настоящее локальное
  TCP-соединение с автоматическим выбором семейства и без него. Тест не
  требует ключей, баз данных, очередей или изменения подписок площадок.
- **Приёмка в рабочем окружении:** после обновления сборки выполнить
  `bun run channels:check avito-npo-automotiv` с уже настроенными переменными
  окружения. Проверка локального транспорта не подтверждает доступность
  API и права аккаунта в рабочем окружении.
