# manager: поэтапный план

Редакция 0.5 · 11.09.2026 · **первая фаза принята, вторая разрешена владельцем**.
Задача и рабочая ветка: `manager`.

Цель: сообщения и файлы с сайта поступают в общий раздел СЭП Чата,
менеджеры отвечают от своего имени, видят историю клиента и связывают его
с контактом ЕРП. Недоступный сервис полностью скрывает виджет.

## Матрица сквозной приёмки

| Проверка | Ожидаемый результат |
| --- | --- |
| Сервис недоступен при загрузке сайта | Кнопка, Popover и окно отсутствуют, сайт работает |
| Связь пропала во время формы | Виджет скрыт после обнаружения; состояние страницы сохранено |
| Сервис восстановился | Кнопка доступна; черновик сохранён; нет дублей или самораскрытия |
| Вне рабочего времени при исправном сервисе | Виджет доступен, офлайн-статус соответствует расписанию |
| Первая отправка и форма | Ровно один согласованный процесс приёма, текст/файлы не теряются |
| Повтор запроса после таймаута | Один топик и одно сообщение |
| Одновременные ответы A и B | Оба доставлены; ответственным стал первый по порядку сохранения |
| Ручное назначение до запоздалого первого ответа | Ручное назначение сохранено |
| Ответ другого менеджера после назначения | Автор отображается правильно, ответственный прежний |
| Другая платформа того же клиента | Менеджер видит связь/историю; ответ маршрутизируется в исходный диалог |
| Клиент запросил прежний или чужой диалог | Отказ; ни сообщения, ни реквизиты, ни файлы не выданы |
| Телефон и email совпали с разными контактами | Конфликт показан менеджеру, автоматического слияния нет |
| Два запуска синхронизации/таймаут после commit ЕРП | Один контакт, один результат операции, сохранён инициатор |
| ЕРП недоступна | Диалог работает, синхронизация не показана успешной |
| Роль выдана | Сотрудник видит все разрешённые обращения, включая прежние |
| Право изменено у роли, сотрудник не перелогинивался | Полномочия обновлены в согласованный срок |
| Роль отозвана при открытом чате | Нет новых чтений/отправок/событий и файлов; раздел и кеш очищены |
| Ссылка на вложение/превью открыта без права | Отказ, включая прямой общий маршрут хранилища |
| Перезапуск после сохранения и до отправки события | Доставка восстановлена, сообщения и контакты не продублированы |
| Общие компоненты обновлены | Существующие чат, файлы, комментарии, Popover и навигация проходят регрессию |

## Результат этапа 1 — 10.09.2026

В manager-client реализованы загрузчик с iframe, конфигурация, все описанные
экраны, гостевой HTTP/WebSocket-транспорт и отдельный локальный демосервер.
Фактические методы записаны в [контракте](../../manager-client/docs/RUNTIME_CONTRACT.md).
Новые общие оболочка сообщения, карточка/иконка файла подключены в yui и чате.

Проверки: 6 модульных тестов виджета, 14 браузерных сценариев, отдельный
сценарий собранного виджета на разных origin; проверка настоящих компонентов
чата и прежнего режима редактора; проверки типов и сборки. Полный запуск
комментариев в ЕРП и реальные мобильные устройства остаются перед выпуском.

Демонстрационные значения D-01–D-03: пн–пт 08:00–18:00 MSK, все три поля,
первая доставка после формы. Это не отдельное подтверждение производственного
расписания. См. журнал решений и README виджета.

Перед открытым выпуском: выбрать лицензию, выпустить общие компоненты yui,
обновить зависимости обоих клиентов и уменьшить размер пакета для iframe
(сейчас около 1.07 МБ gzip вместе с CSS). Служебный сервер, роли и ЕРП ещё
не реализованы; этапы 2 и 3 не отмечаются выполненными.
